## Milestone Synthesis & Version History

- **v0.1 (Milestone M0 — Preparation Release)**: Runnable exact-counting lab with 20 unittests, 160 smoke counts independently recomputed by truth-table oracle, and strict budget semantics.
- **v0.2.1 (Milestones M1–M3 & Calibrated Benchmarks)**: Resolution of M1 with formal blocker, execution of M2 train slice and M3 held-out evaluation (1,200 runs with negative speedup result), Hypothesis H4 graph separator study (160 runs), and calibrated scaling benchmark across $n=12..20$ (300 runs).
- **v0.2.2 (Milestone M5 — Useful Transfer Baseline)**: Weighted Model Counting (WMC) engine, network infrastructure reliability compiler (`evidence/wmc-reliability-001/`), high-core parallel Cube-and-Conquer lookahead on AMD EPYC (302 runs evaluating 194,165,819 search nodes in `epyc-cube-001` and `epyc-cube-002`), and tensor network contraction study (`tensor-study-001`).
- **v0.2.3 (Commercialization Baseline)**: Dual Cut Monotone CNF compilation (`cut_compiler.py`), Multi-Terminal $K$-Cut compilation (`k_cut_compiler.py`), Enterprise Reliability & SLA Audit SDK (`sat_frontier/enterprise/`), Birnbaum sensitivity index engine, and 5 mission-critical commercial benchmarks (`evidence/commercial-benchmarks-001/`).
- **v0.2.4 (Breakthrough Extensions)**: Algebraic Model Counting over $\mathbb{Z}[x]$ (`poly_wmc.py`), Directed Dicut compilation (`dicut_compiler.py`), and continuous percolation susceptibility analysis.
- **v0.2.5 (Network-Wide Centrality & Mixed Failures)**: Dual Mixed-Cut compilation for simultaneous node and edge failures (`mixed_cut_compiler.py`) and all-pairs SLA availability matrix and centrality engine (`all_pairs.py`).
- **v0.2.6 (Correlated Multi-Failures & High-Core EPYC Frontier)**: Shared-Risk Resource Group (SRRG) compilation (`srrg_compiler.py`), pre-compiled high-core EPYC cut frontier benchmarks (`instances/epyc-cut-frontier/`), and turnkey execution directive (`docs/HERMES_TERRA_EPYC_DIRECTIVE.md`).
- **v0.2.7 (Frontier Breakthrough Release)**: Continuous Temporal Network Reliability & Exact Closed-Form Algebraic MTTF Integration (`temporal_reliability.py`), Capacitated Network Flow Reliability (`capacitated_compiler.py`), Bounded-Diameter / Latency-Constrained Reliability (`bounded_hop_compiler.py`), Interactive Web Visualizer & SLA Dashboard (`sat_frontier/enterprise/web/index.html`), and Formal Verification in Lean 4 (`lean/CutDuality.lean`).
- **v0.2.8 (Current Production & Frontier Breakthrough Release)**: Multi-Commodity Capacitated Flow Reliability via Dual Multi-Cut Compilation (`multi_commodity_compiler.py`, Hypothesis H18), Dual Multi-Cut Duality Theorem (Theorem 10) with strictly $|E|$ physical edge variables and zero auxiliary variables, pure Lean 4 formal verification of Exact Algebraic MTTF Integration (`lean/AlgebraicReliability.lean`) and Multi-Commodity Duality (`lean/MultiCommodityDuality.lean`), turnkey Desktop UI application runtime and launcher (`sat_frontier/enterprise/desktop.py`, `scripts/launch_dashboard.py`), full web visualizer multi-commodity mode, and 24-instance empirical study (`evidence/multi-commodity-wmc-001/`) with 24/24 exact rational oracle matches.

Total empirical evidence base: **20 complete suites, 2,798 verified runs, 100% cryptographic SHA-256 integrity**.
